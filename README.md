# 🎵 MP — локальный MP3-плеер с приёмом файлов из мессенджеров

**MP** — минималистичный офлайн-плеер для Android на Flutter. Сканирует память телефона, копирует найденные MP3 в приватную папку приложения, позволяет управлять собственной музыкальной коллекцией (сортировать, слушать, делиться треками, читать тексты песен). Дополнительно MP принимает аудиофайлы из системного меню «Поделиться» и «Открыть с помощью», умеет работать в роли плеера по умолчанию и — при желании — массово чистить голосовые сообщения из WhatsApp прямо из интерфейса «Все MP3 на устройстве».

В репозитории также лежит **стартовый плейлист** — несколько оригинальных песен автора проекта, которые можно слушать сразу после установки.

## ✨ Возможности

- 🔍 **Поиск MP3 на устройстве** — через `MediaStore` и обход общих папок, с копированием файлов в приватное хранилище (оригиналы на телефоне остаются нетронутыми).
- 📋 **Управляемая библиотека** — перестановка треков стрелками ↑↓, удаление из списка (файл на телефоне сохраняется).
- 🎧 **Фоновое воспроизведение** — через `audio_service` и `just_audio`, с управлением из уведомления и экрана блокировки.
- 🖼 **Обложки** — из метаданных MP3; если её нет — детерминированный коллаж из `assets/collages/`.
- 📜 **Текст песни** — чтение ID3-тега `USLT` (кнопка «Т» на обложке в плеере).
- 📤 **Массовая отправка** — долгое нажатие на ➦ в списке включает режим выбора (до 10 треков) и открывает системный шит «Поделиться».
- 📥 **Приём файлов из других приложений** — MP появляется в «Поделиться» и «Открыть с помощью» для `audio/*`. Файл копируется в библиотеку; при открытии из файлового менеджера — ещё и сразу воспроизводится.
- ⭐ **Работа в роли плеера по умолчанию** — через системный chooser с объясняющим диалогом (прямого API нет, см. раздел ниже).
- 🧹 **Массовая очистка голосовых сообщений** — выделение сотен и тысяч файлов в WhatsApp/Media и удаление за один проход (проверено на 2300+ голосовых). Для MAX — см. ограничения ниже.
- 🎨 **Тёмная и светлая темы** — автоматически по системной настройке.
- 🇷🇺 **Русский интерфейс** — `Locale('ru')` по умолчанию.
- 🎁 **Стартовый плейлист** — 12 оригинальных песен автора вшиты в APK, доступны сразу после установки.

📥 Приём файлов из других приложений

MP регистрирует два intent-фильтра в MainActivity (AndroidManifest.xml):
Фильтр	Действие	Когда срабатывает
ACTION_SEND	«Поделиться → MP»	в мессенджере / файловом менеджере вы жмёте «Поделиться» на mp3
ACTION_VIEW	«Открыть в MP»	тап на mp3 в файловом менеджере, «Открыть с помощью» → MP; клик по ссылке на mp3 в браузере

Что происходит при получении файла:

    MainActivity (Kotlin) копирует содержимое content:// во временный файл в cacheDir, разбирая ContentResolver и DISPLAY_NAME.

    Flutter забирает путь через ShareReceiver (lib/core/utils/share_receiver.dart).

    TrackRepository.importLocalFile читает теги, копирует файл в приватную папку mp3_library/, сохраняет обложку в covers/, добавляет запись в SQLite.

    Временный файл удаляется.

    Если это был ACTION_VIEW — трек сразу загружается в очередь и стартует воспроизведение. Если ACTION_SEND — просто появляется в библиотеке с snackbar «Добавлено: …».

Обработка работает в трёх сценариях:

    Холодный старт — файл пришёл до готовности Flutter. MainActivity держит его в pending, Dart забирает через getPendingFile() при первом initState.

    Приложение уже открыто — onNewIntent → deliverPending() → событие onSharedFile по MethodChannel.

    Страховка на AppLifecycleState.resumed — если Dart-обработчик по какой-то причине был не зарегистрирован, takePending() подберёт файл при возврате в приложение.

launchMode="singleTask" — важно для стабильности: файловые менеджеры присылают intent с FLAG_ACTIVITY_NEW_TASK, и без singleTask Android в ряде случаев создаёт второй экземпляр MainActivity, что при фоновом воспроизведении может привести к чёрному экрану (Activity создана, но Flutter-движок не прицепился). С singleTask intent всегда идёт через onNewIntent в существующий экземпляр.
⭐ Плеер по умолчанию

Android не даёт приложению назначить себя «по умолчанию» в один клик — это всегда выбор пользователя. Поэтому MP действует через два механизма:

    Системный chooser — кнопка ⭐ в AppBar экрана «Все MP3 на устройстве» открывает объясняющий диалог, из которого можно вызвать системный выбор приложений для audio/mpeg. Пользователь видит MP в списке и жмёт «Всегда».

    Настройки Android — тот же диалог предлагает открыть экран «Приложения по умолчанию» (Settings.ACTION_MANAGE_DEFAULT_APPS_SETTINGS, API 24+), если нужно сбросить ранее данный другому плееру выбор.

После выбора «Всегда» на любом mp3-файле система сама передаёт intent в MP — с этим и работает ACTION_VIEW из раздела выше.

Ограничение: Android 11+ иногда помнит выбор по MIME-type; если «Всегда» было дано другому плееру, его придётся сбросить вручную через «Приложения по умолчанию» → «Аудио».
🧹 Очистка голосовых сообщений из мессенджеров

На экране Настройки → «Все MP3 на устройстве» MP сканирует общие папки мессенджеров. Голосовые сообщения — это обычные .mp3 / .opus / .m4a, они попадают в общий список. Их можно выделить (долгое нажатие → режим выбора) и удалить пачкой. Массовое удаление сопровождается прогресс-диалогом с кнопкой «Прервать».
Что работает

✅ WhatsApp — голосовые лежат в /storage/emulated/0/WhatsApp/Media/WhatsApp Audio/, .../WhatsApp Voice Notes/, .../Sent/. Доступны после выдачи разрешения «Доступ ко всем файлам» (MANAGE_EXTERNAL_STORAGE, Android 11+) или обычного READ_EXTERNAL_STORAGE на Android ≤ 10. Проверено на практике — тысячи голосовых удаляются за один проход (2300+ на одном устройстве).
Что ограничено

⚠️ Telegram — голосовые лежат в /storage/emulated/0/Android/data/org.telegram.messenger/files/…. На Android 11+ этот путь недоступен без root. На Android ≤ 10 (или устаревших прошивках) MP их увидит.

❌ MAX (ru.max / ru.max.messenger) — голосовые в Android/data/ru.max/cache/upload/. Даже с выданным «Достпом ко всем файлам» Android 11+ блокирует чтение Android/data/<package>/ на большинстве устройств. Это ограничение самой ОС, а не приложения. Часть файлов MAX может попасть в общие папки (Music/MAX, Download/MAX) — MP их сканирует, но полную очистку голосовых MAX через MP сделать нельзя.
Важно

Удаление файлов безвозвратное. Перед стартом показывается подтверждение с количеством файлов и предупреждением, что отменить операцию нельзя. Если случайно удалили не то — файл можно найти в корзине файлового менеджера (зависит от прошивки) или восстановить из облачного бэкапа.

🎼 Стартовый плейлист
В APK вшиты 12 оригинальных треков автора. При первом запуске они копируются в приватное хранилище и появляются в библиотеке как обычные треки. Пользователь может их удалить — они не вернутся (флаг в SharedPreferences).

Полный список — в assets/preinstalled/. Все песни написаны и исполнены автором проекта и распространяются по отдельной лицензии (см. ниже).
