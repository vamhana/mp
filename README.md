# 🎵 MP — локальный MP3-плеер

**MP** — это минималистичный офлайн-плеер для Android, написанный на Flutter. Он сканирует память телефона, копирует найденные MP3 в приватную папку приложения и позволяет управлять собственной музыкальной коллекцией: сортировать, слушать, делиться треками и читать тексты песен прямо с обложки.

В репозитории также лежит **стартовый плейлист** — несколько оригинальных песен автора проекта, которые можно слушать сразу после установки.

---

## ✨ Возможности

- 🔍 **Поиск MP3 на устройстве** — через `MediaStore`, с копированием файлов в приватное хранилище (чтобы оригиналы на телефоне оставались нетронутыми).
- 📋 **Управляемая библиотека** — перестановка треков стрелками ↑↓, удаление из списка (файл на телефоне сохраняется).
- 🎧 **Фоновое воспроизведение** — через `audio_service` и `just_audio`, с управлением из уведомления и экрана блокировки.
- 🖼 **Обложки** — из метаданных MP3; если её нет — детерминированный коллаж из `assets/collages/`.
- 📜 **Текст песни** — чтение ID3-тега `USLT` (кнопка «Т» на обложке в плеере).
- 📤 **Массовая отправка** — долгое нажатие на ➦ в списке включает режим выбора (до 10 треков) и открывает системный шит «Поделиться».
- 🎨 **Тёмная и светлая темы** — автоматически по системной настройке.
- 🇷🇺 **Русский интерфейс** — `Locale('ru')` по умолчанию.
- 🎁 **Стартовый плейлист** — 12 оригинальных песен автора вшиты в APK, доступны сразу после установки.

## 🛠 Стек

| Слой | Технологии |
|---|---|
| UI | Flutter, Material 3, Riverpod |
| Аудио | `audio_service`, `just_audio` |
| Метаданные | `audio_metadata_reader`, `on_audio_query` |
| Хранилище | `sqflite`, `path_provider`, `shared_preferences` |
| Разрешения | `permission_handler`, `device_info_plus` |
| Утилиты | `share_plus`, `marquee`, `flutter_localizations` |

Минимальная версия Android — **API 21** (Android 5.0). Полноценно протестировано на Android 13 (API 33) и Android 14.

## 🚀 Сборка и запуск

### Требования

- Flutter **3.24+** (Dart 3.5+)
- Android SDK **API 34**
- JDK 17

### Шаги

```bash
git clone https://github.com/vamhana/mp.git
cd mp
flutter pub get
flutter run
```

Сборка релизного APK
```bash
flutter build apk --release
# результат: build/app/outputs/flutter-apk/app-release.apk
```
скачать и установить плеер мгновенно:
```
https://github.com/vamhana/mp/releases/download/v0.0.02/app-release.apk
```
GitHub Releases в России периодически отдаёт `504 Gateway Timeout` из-за проблем с CDN. скачать релиз:

- **APK:** [app-release.apk (163 MB)]
```
https://github.com/vamhana/mp/releases/
```
📂 Структура проекта
```
lib/
├── app.dart                          # корень приложения, темы, локализация
├── main.dart                         # точка входа
├── core/utils/                       # утилиты (коллажи, текст, разрешения, шеринг)
├── data/
│   ├── datasources/                  # сканер MediaStore, SQLite, копирование файлов
│   ├── models/track.dart             # модель трека
│   └── repositories/                 # TrackRepository (синхронизация, удаление, порядок)
├── presentation/
│   ├── providers/                    # Riverpod-провайдеры
│   └── screens/                      # Home, Library, Player, Settings
└── services/audio_handler.dart       # MpAudioHandler (audio_service + just_audio)
Аудиофайлы для стартового плейлиста лежат в assets/preinstalled/, коллажи — в assets/collages/, иконка приложения — assets/icon.png.
```

🎼 Стартовый плейлист
В APK вшиты 12 оригинальных треков автора. При первом запуске они копируются в приватное хранилище и появляются в библиотеке как обычные треки. Пользователь может их удалить — они не вернутся (флаг в SharedPreferences).

Полный список — в assets/preinstalled/. Все песни написаны и исполнены автором проекта и распространяются по отдельной лицензии (см. ниже).
